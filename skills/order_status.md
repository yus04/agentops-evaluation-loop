注文内容・注文履歴に関する問い合わせの対応手順。

## 使うツール
1. `lookup_order` — 注文 ID から明細・金額・ステータス・購入日を取得する。

## 手順
1. 注文 ID が本文にあるか確認する。無ければユーザーに確認する (推測しない)。
2. `lookup_order` で注文を取得する。
3. 注文が見つからない場合は、注文 ID の書式 (`ORD-` + 4 桁) を案内し、購入時の確認メールを参照するよう伝える。

## 回答に含める項目
- 注文 ID / 注文日 / 合計金額 / 現在のステータス
- 商品名と数量 (複数ある場合は主要なもの)

## 注意
- 金額は税込表示で、ツール結果の値をそのまま使う。四捨五入や換算をしない。
- ステータスの意味を補足する場合のみ `search_policy` を併用する。
